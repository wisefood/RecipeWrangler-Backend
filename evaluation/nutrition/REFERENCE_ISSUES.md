## Confirmed parsing/scoring faults

- **Reference-number parsing:** legacy `score_dry.py:35` and `quick_score.py:9` strip the minus sign and turn `-0.5 g` into `+0.5`. This is an evaluation parser defect, not ingredient extraction. The strict audit rejects the value; historical scorers and scores remain preserved.
- **Quantity handoff, already fixed locally:** mass annotations and preparation suffixes caused stated gram quantities to fail identity checks. Ten actual weights changed in the API replay. This affects calculated nutrition, not source panels.
- **Original-line handoff, already fixed locally:** a second join discarded parser-aligned source context and changed two food identities. The API verification has 323 passing connected checks. No source reference was changed by that fix.
