# Sustainability

**No accuracy evaluation exists.** There is no open English recipe dataset with independent full-recipe footprint ground truth. Public sets (RecipeEmission, GreenFoodLens) are modelled estimates, and shared reference factors cannot give an independent accuracy claim. Last updated 4 November 2026.

## What was done

| Item | Result |
|---|---|
| Reference data | 13,032 factors from AGRIBALYSE 3.2, SU-EATABLE LIFE, CONCITO and FoodEx2 mappings, merged by a source-aware policy into one versioned Elasticsearch index. 112 tests pass. |
| Recipe-level shadow run | 100 profiles: 120 of 1,060 ingredient positions matched, no complete recipes under the single-source policy |
| Embeddings | 10,834 distinct source names embedded (BGE) for all 13,032 references |
| Deployment | API image not redeployed. Stored recipe scores unchanged. |

Current app method: sum of ingredient kg x kg CO2e/kg from "Sustainable FooDB". It measures climate impact only. Missing factors count as zero, a known limitation.

## Adaptation rework, 17 November

Dev set: the 537 Living Lab recipes in their native region (offline review of the saved 11 Nov inputs, no LLM, no writes). Code: `services/adaptation/sustainability_adaptation.py` and `sustainability_swap_rules.py`; CO2e factors come from the reviewed AGRIBALYSE 3.2 name mapping (local analysis folder), injected so the package does not depend on it.

**LLM stage (18 Nov, local vLLM Qwen3-32B-AWQ, owner OK; last pass on the vLLM shared with the nutrition session, 1 worker):** choice + rewrite on the adapted recipes, reusing the nutrition stage unchanged (`analysis/sustainability-adaptation-2026-11-17/llm_sus.py`, CO2e choice prompt, cook-name labels, notes, half-lentil lines and extra validators patched at runtime). Review of all rewrites found and fixed: junk swap targets (breaded, takeaway, casing, stuffed, gravy, smoked, luncheon, goose, duck; swaps to another red meat blocked; sweetener for sweetener blocked; regional table first with EU fallback); the empty source line; half-lentil swaps read as a full replacement (now `Nx g meat, plus Nx g cooked lentils`, meat kept in title and steps, lentils added to the first step that names the meat, protein note); wrong generic notes ("sardines are leaner than tuna"); database wording in lines and tips (cook names: chicken, chicken mince, hake, sardines, margarine, mozzarella, Greek yogurt); a replaced food left in a title or step ("Beef chilli" with chicken mince, "beef" next to "your chicken"); doubled words. Swap text (owner, 18 Nov): the only text a swap carries is one code-written sentence, "We replace the X with Y because it has N% lower CO2e per kg, which cuts this recipe's footprint by M% (K kg CO2e per serving)"; no cooking, nutrition or indicative notes (the indicative flag stays in the candidate data). Result: 105 adapted (after the no-stated-amount guard), 105 rewrites ok (the last 3, which the local model failed, were rewritten through OpenRouter qwen/qwen3-32b under a $0.10 capped ledger, 8 calls, 12.6k tokens, well under $0.01; hosted only for those three), 0 old food left, 0 database wording except lines that were already database-style in the source recipe (2). Not done: end-to-end pipeline recheck, white-fish shared proxy (12.0) is a data limit of AGRIBALYSE, indicative note shown.

**End-to-end check (18 Nov, 30 of 103 rewritten recipes, stratified by swap type and region, parse/weight LLM on the shared local vLLM, CPU matcher on 1 core, 0 failures):** original and final text through the production profiling chain (`e2e_sus.py`, `e2e_report_sus.py`, `e2e/`). Criteria fixed beforehand: C1 pipeline CO2e per serving goes down, C2 relative cut >= half the claimed cut, C3 no new allergen. Result: 21 ok, 6 gain smaller than claimed, 3 not lower, 0 new allergens. Meat to poultry and mince (the 95% of the saving), butter to margarine, half lentils and hard cheese to mozzarella in cheese dishes agree (pipeline 45-95% cuts vs 12-89% claimed; claimed is AGRIBALYSE, the pipeline uses its own sustainability factors, median pipeline/claimed baseline 0.61). Misses: cod to hake (pipeline 1.03 to 2.63), veal ribs to chicken (pipeline veal baseline 0.145 vs claimed 2.98), crème fraîche to yogurt (-1%), tuna to sardines in tin-count lines (the parser reads '2 tins' as 2 g, both sides equal), cheddar to mozzarella in two small-cheese recipes, spreads. Cause is the pipeline's factors and parser, not the rewrite: the rewritten lines parse to the right foods and weights. Resolve when wiring: the pipeline must use the signed-off AGRIBALYSE mapping, then rerun this check.

**Pipeline switch, applied to the working tree (18 Nov, uncommitted):** the legacy Sustainable FooDB path in `sustainability_calculator.py` is replaced by the reviewed AGRIBALYSE name mapping (`tools/sustainability_factors.py`, data in `tools/data/`; CONCITO and role average only complete totals; name-only matching scores 492 vs 497 of 537 recipes). `best_sustainability_match` keeps its signature, so `/adapt/enhance` (service.py) uses the same factors. FooDB data kept (legacy). `sustainability_references.py` is NOT unused: `/adapt/enhance` (impact_objectives.py, enhancement.py) and several scripts still read its AGRIBALYSE reference index, a second AGRIBALYSE path next to the new mapping. Full suite 5382 passed, 0 failed. Parser fix: `2 tins of X, approx. 198g` now gives 2 x 198 g (a generic override had replaced even a correct model total with the leading count); tests added. Red meat to another red meat is allowed again (owner); goose, duck and game stay excluded as stand-ins. A line with no stated amount ('creme fraiche') is no longer a swap source (its weight is a guess; reason code amount_not_stated), 105 adapted. Final end-to-end check on the applied pipeline, 29 recipes: 29 ok, 0 failed, median pipeline/claimed baseline 1.0.

**Read endpoint (18 Nov, uncommitted):** `GET /api/v1/recipes/{recipe_id}/adaptations?mode=sustainability&region=IE|HU|SI|EU` returns the stored row (`status`, `is_adapted`, original and adapted text, swap, benefit with the CO2e sentence); a recipe without a suggestion returns `reason_code` and a `reason` sentence; 404 when no row exists. 47 of the 108 are red meat to poultry or poultry-mince swaps, which carry most of the total saving. The 108 recipes hold 56% of the dev set's CO2e and their best swaps remove 33% of it. 66 of 108 change a food named in the title (flagged, not blocked). Provisional: the reviewed mapping (beef, lamb, minced beef carry 40% of the CO2e) is not signed off yet.

- Diagnosis: only ingredients carrying >= 20% of the recipe CO2e are changed. Vegetables, fruit, onions, roots, herbs, pulses, nuts, protected foods (eggs, whole fruit, oily fish, whole nuts and seeds, avocado), prepared products, rice in rice dishes, whipped/frozen cream and raw-eaten dishes are never changed.
- Gates: saving >= 10% of the recipe and >= 0.05 kg CO2e per serving; shared role filter (lenient) plus sustainability guards (no olive oil, no cream/yogurt to milk, cheese keeps its texture, rice stays a whole grain, no cooked/raw record mix, no squid to fish, no bread to grain); allergen/diet gate. **Nutrition is not judged** (owner, 18 Nov: sustainability is a separate facet; no Nutri-Score, saturated-fat, sodium or sugar check). Swaps that the old nutrition guard used to hide as a side effect now have explicit culinary rules: no rillettes, pate, nuggets or frankfurter in place of plain meat, no lard, back fat, brain or other offal, no kefir for yogurt, no icing sugar for syrup, no low-fat spread for butter, fish for fish only through the table rows.
- Curated table: red meat to poultry, red mince to poultry mince, butter to margarine (same factor as sunflower oil, works in mash, baking and spreading), hard cheese to mozzarella, double cream to single cream. Owner, 17 Nov: allow swaps of the food named in the title (flagged); drop grain swaps and feta to cottage cheese; butter to margarine only (no oil). Cod, haddock, pollock, whiting and plaice to hake or saithe is back as an indicative swap (owner, 18 Nov): the saving rests on one shared AGRIBALYSE value (12.0, identical on every indicator) against hake's own 7.59, so the UI must call it indicative. Other fish-for-fish swaps from these white fish stay blocked. AGRIBALYSE gives cod, haddock, pollock, whiting and plaice one shared value (12.0, identical on every indicator) while hake has its own (7.59), so that saving is indicative only.
- With the table hidden, search finds the same target in 28 of 43 table-led recipes and another swap on the same line in 4.
- Mapping fixes found on the way: bell peppers counted as black pepper, leek as onion, peanut butter as butter, chicken/beef stock as meat, beef tomato as beef, "plain" and "cow's milk" in record names sending pasta, yogurt and cheeses to the flour and milk factors.

- 17 Nov, more adaptations (owner: "there are sensible swaps, we need more"): canned tuna to sardines, mackerel or herring ; prawns to mussels; half of a chicken, turkey or meat line replaced by the same weight of cooked lentils, only in stewed or curried dishes (15 recipes; protein drops, flagged for the nutrition facet); cooked pork ham to turkey or chicken ham (AGRIBALYSE 7.65 to 5.9, about a quarter less, so only 1 recipe clears the 10% floor); bacon and salami have poultry versions in the tables but the saving is under the floor. Cured hams (prosciutto) are never swapped. Plant-based, fat and skin records are never targets. Plant drinks for milk are not possible: the soy and almond drinks add an allergen the recipe lacks and there is no oat drink record in AGRIBALYSE.
- Bone-in red meat (18 Nov): chops, cutlets, ribs and joints go to chicken or turkey weighed as edible meat, not at the same weight. Edible fractions from ReFED's table of USDA refuse percentages (pork chops 75%, spareribs 70%, lamb chops and cutlets 75%, lamb leg and shoulder 82%, veal ribs and chops 67%, beef ribs 71%, other beef 77%, default 80%): 452 g of pork chops becomes 339 g of chicken, and the saving compares edible with edible. 6 more recipes (4 pork-chop dishes, lamb cutlet casserole 6.2 kg CO2e per serving saved, beef casserole). Bone-in poultry stays unchanged.
- Every recipe with no suggestion carries a reason code and sentence (`why_no_suggestion`): no lower-impact option (181), already low-impact (72), main food protected (48), prepared product (37), saving too small (30), main food defines the dish (11), estimate only (6), allergen (4). A check of the rejected candidates found animal fat records (chicken fat, goose fat) were being offered as targets for poultry; they are now blocked, which moved 33 chicken recipes from "fail nutrition" to the accurate "no lower-impact option".
- Source policy (owner, 17 Nov): AGRIBALYSE first; CONCITO only where AGRIBALYSE has no record (GB for Irish, FR otherwise: mushroom, wine, olives, pesto, pickles, wheat) and role averages as marked estimates. Fallback factors complete a recipe's total but are never the swapped food or a swap target, so every saving compares two AGRIBALYSE foods. 47 more recipes became scorable (87 -> 40 unscored); 34 hotspots with only a fallback factor get no swap. Source data is ranked, not deleted. SU-EATABLE and the legacy FooDB table are not used. Sources measure different things (AGRIBALYSE attributional, CONCITO consequential), see the 3 Nov report.
- Ingredient -> CO2 record matching (17 Nov): when the nutrition matcher picked a CIQUAL record, the AGRIBALYSE factor is joined by CIQUAL code (15% of CO2e); otherwise reviewed name rules on the recipe wording (42%) or, when the wording is a bare word like "cheese", on the matched record name (41%); CONCITO and estimates < 1%. Doughs, cakes, soups and pies get no factor rather than their first ingredient's. An audit of every ingredient line (`audit_matches.py` in the local analysis folder) leaves 43 questionable pairs carrying 1.4% of CO2e; it found and fixed eggs read as chicken, half-fat cheddar as cream, quark and matured cheese as milk, walnut cake dough as walnuts, "in rapeseed oil" and "without sugar" read as the food.
- The 40 still unscored are mostly composites with no factor in any source (doughs, sauces, soups, fillings).

Limits: 437 have no suggestion (169 have no changeable hotspot; most of the rest already use the lowest-CO2e food of their kind, e.g. chicken, pasta, milk); liquid stock counts as water; AGRIBALYSE is the French reference scenario, not regional.
